Every official except an admin works one event, shown on their phone. Lane officials need a track and lane (or tick “one code per lane”). Track operators without a track can run any of their event's tracks. A vote official records scouts' choice votes on a tablet. Finished events aren't listed. Codes expire after a few minutes, unless you tick “Printable”: those work for any number of phones until you revoke them or the event is finished, so you can print them once and tape them up at each station. Admin codes can't be printable.
